💬
WhatsApp Business API
Meta Cloud API · שליחת הודעות להורים ישירות מהמערכת
1
פתיחת חשבון Meta Business
נדרש חשבון Meta Business Manager. אם אין — פותחים ב: business.facebook.com
2
הוספת מספר טלפון לWhatsApp Business
ב-Meta Developer Console → יצירת App → WhatsApp → הוספת מספר טלפון ייעודי (לא מספר אישי!). מספר ה-ID שמתקבל זה WHATSAPP_PHONE_ID
3
קבלת Access Token
ב-Meta App Dashboard → System Users → Generate Token. זהו WHATSAPP_TOKEN
4
הוספת משתני סביבה ב-Vercel
ב-Vercel → Settings → Environment Variables, להוסיף:
WHATSAPP_TOKEN=EAAxxxxx... WHATSAPP_PHONE_ID=123456789
5
רישום Webhook ב-Meta
ב-Meta App → Webhooks, להגדיר URL:
https://chabad-kaitanot-d2em.vercel.app/api/whatsapp
6
✓ הקוד כבר מוכן במערכת
API route קיים ב-/api/whatsapp · כפתור "שלח WhatsApp" קיים במסך הנרשמים
💳 מה נדרש להפעלת מערכת סליקה (Cardcom)
💳
Cardcom — סליקת אשראי ישראלית
שליחת קישור תשלום להורים · עדכון אוטומטי של סטטוס תשלום
1
פתיחת חשבון סוחר ב-Cardcom
פנו ל-Cardcom בטלפון 03-7219966 או ב-cardcom.solutions לפתיחת חשבון עסקי עבור הרשת
2
קבלת פרטי API
לאחר אישור החשבון, Cardcom שולחים:
Terminal ID → CARDCOM_TERMINAL API Name → CARDCOM_API_NAME API Password → CARDCOM_API_PASSWORD
3
הוספת משתני סביבה ב-Vercel
ב-Vercel → Settings → Environment Variables, להוסיף את 3 הפרטים שקיבלתם מ-Cardcom
4
הגדרת Webhook ב-Cardcom
בחשבון Cardcom → הגדרות → Webhook URL:
https://chabad-kaitanot-d2em.vercel.app/api/payments/webhook
5
✓ הקוד כבר מוכן במערכת
יצירת קישור תשלום ב-/api/payments/cardcom · קבלת webhook ב-/api/payments/webhook · עמוד הצלחה/שגיאה להורה · עדכון אוטומטי של סטטוס תשלום בנרשם
